
# 🧾 Bill Splitter App

A simple and interactive   React application   that helps you split bills with friends fairly. Add friends, manage balances, and see who owes whom — all in a clean and intuitive interface.

---

## 🚀 Project Overview

The   Bill Splitter App   allows users to:
- Add and remove friends dynamically
- Track balances between you and each friend
- Split expenses evenly or based on who paid
- Keep a running balance history for each friend

---

## 🧩 Features

✅ Add new friends with a name and avatar  
✅ Select a friend to view and split bills  
✅ Update balances based on payment responsibility  
✅ Remove friends from your list  
✅ Dynamic and responsive interface  

---

## 🛠️ Tech Stack

-   React.js   – Component-based UI framework  
-   JavaScript (ES6+)   – For logic and state management  
-   CSS   – For basic styling and layout  
-   UUID / Crypto API   – For generating unique friend IDs  

---

## ⚙️ How It Works

1.   Add Friends:   Enter a friend’s name and image URL.  
2.   Select Friend:   Choose someone from your list to split a bill.  
3.   Enter Bill Info:   Input total bill and how much you paid.  
4.   Choose Payer:   Select who covered the bill.  
5.   Split:   The app automatically adjusts balances — showing who owes whom.

---

## 🧰 Installation & Setup

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/yourusername/bill-splitter-app.git

# Navigate into the folder
cd bill-splitter-app

# Install dependencies
npm install

# Start the development server
npm start
````

The app will open at   [http://localhost:3000/](http://localhost:3000/)   by default.
